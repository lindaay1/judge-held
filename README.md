# The Evening Saved You a Seat

`main.py` (Python 3, standard library only, no dependencies, no network)
writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).

The entry (248 Unicode code points):

> Somewhere, rain is falling on a tin roof, slow and unhurried, and a kettle is coming to the boil for no one in particular. Nothing here needs you to be clever or quick. Stay a little longer. The evening has already saved you a seat, and it is warm.
